## Codebase Patterns
- 项目不是 git 仓库，运行在 macOS 沙盒环境（WeChat 容器），无法执行 vite build（rolldown 原生绑定被系统策略阻止）。用 `npx vue-tsc -b` 作为 typecheck 验证。
- vitest / vite dev server 同样因 rolldown 绑定失败无法在沙盒中使用。浏览器验证需使用 `node --test scripts/*.mjs` 替代，用 Node.js 内置 `node:test` 模块编写单元测试。
- `erasableSyntaxOnly: true` 已启用（TypeScript 6.0），不能使用 `enum` 语法，用 `const` 对象 + `type` 联合替代。
- Fabric.js v5.x 通过 `import { fabric } from 'fabric'` 导入，`@types/fabric` 已安装。
- Boot 流程：BootLoader → InitDataParser/UrlParamParser → ConfigResolver → BootConfig → screenStore。
- 初始化数据通过 `window.__ESL_EDITOR_INIT__` 全局变量或 URL `?init=<base64>` 传入。
- ScreenProfile 使用预定义 profiles（BW/TRI/BWRY/SIX），外部 palette 格式为 `{ name, value(hex) }`，内部为 `{ name, hex, rgb, deviceIndex }`。
- `BootConfig` 是全局配置对象，存储在 `screenStore` 中，`EditorCore` 和所有插件都依赖它。
- BootPhase 已改为 const 对象（非 enum），用于 BootView 的状态显示。
